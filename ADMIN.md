# Админка SiteNext

Редактируй тексты сайта с любого компьютера через браузер.

## Адрес

После публикации на GitHub Pages:

**https://guzaliya23.github.io/sitenext/admin/**

Локально (если запущен сервер проекта):

**http://127.0.0.1:8880/site/admin/**

## Как войти (один раз на браузер)

1. Открой админку.
2. Нажми **Sign in with Token** (войти по токену).
3. Перейди по ссылке из окна → создай **Fine-grained** или **Classic** token:
   - Classic: галочка **`repo`**
   - Fine-grained: доступ к репозиторию **sitenext**, права **Contents: Read and write**
4. Скопируй токен и вставь в окно админки.
5. Токен сохранится в этом браузере (не свети его в чатах).

## Как править

1. Открой **Страницы → Главная страница**.
2. Поменяй нужные поля.
3. Нажми **Publish** / сохранить.
4. Через 1–2 минуты обнови сайт: https://guzaliya23.github.io/sitenext/

Тексты лежат в файле `content/home.json` в репозитории.

## Важно

- Нужен доступ к GitHub-аккаунту **Guzaliya23** (или collaborator с правом записи).
- GitHub Pages должен быть включён: Settings → Pages → branch `main` → `/ (root)`.
- Дизайн/анимации админка не меняет — только тексты (и позже картинки в `assets/uploads`).
