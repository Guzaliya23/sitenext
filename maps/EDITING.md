# Как самой подвинуть точку на карте

Точки лежат в JSON — править можно без программиста.

## Файл

`maps/<название>/data/locations.json`

Примеры:
- `maps/brat/data/locations.json`
- `maps/piter-fm/data/locations.json`

## Поля координат

```json
"lat": 59.9342,
"lng": 30.1235
```

- `lat` — широта (север–юг)  
- `lng` — долгота (запад–восток)

**Порядок важен:** сначала широта, потом долгота (как в Яндекс.Картах при «Что здесь?»).

## Как взять новые координаты

1. Открой [yandex.ru/maps](https://yandex.ru/maps).
2. Найди нужное место на **суше**.
3. Правый клик → **«Что здесь?»**.
4. Скопируй пару чисел (например `61.0342, 30.1235`).
5. Вставь в JSON в нужный объект (`"order": 1` и т.д.).
6. Сохрани файл.

## Проверка локально

```bash
cd "/Users/rf/Desktop/Лиды редизайн"
python3 -m http.server 8890
```

Открой `http://127.0.0.1:8890/maps/brat/` (или другую карту) и обнови страницу.

## Выложить на сайт

После правок нужен push в GitHub (папка `maps/` в репо sitenext) — можно попросить агента: «залей карты на Pages».

## Частые ошибки

| Симптом | Причина |
|--------|---------|
| Точка в воде | Неверная долгота (`lng`) — часто «уехала» на восток/запад |
| Точка в другом городе | Перепутаны `lat` и `lng` |
| Ничего не изменилось | Не сохранился JSON или открыт кэш / старый URL |
