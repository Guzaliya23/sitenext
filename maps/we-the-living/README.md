# Мы живые — карта маршрута

Интерактивный хронологический маршрут по роману Айн Рэнд «Мы живые».

## Публичная ссылка

https://guzaliya23.github.io/sitenext/we-the-living/

(лежит в репозитории [sitenext](https://github.com/Guzaliya23/sitenext) в папке `we-the-living/`)

## Локально

```bash
cd "/Users/rf/Desktop/Лиды редизайн"
python3 -m http.server 8890
```

http://127.0.0.1:8890/maps/we-the-living/

## Ключ Яндекс.Карт

Прописан в `js/config.js`. В [кабинете разработчика](https://developer.tech.yandex.ru/) укажи HTTP Referer:

- `localhost`
- `*.github.io/*`
- свой домен, если появится

## Точность точек

| Метка | Смысл |
|--------|--------|
| Точная | Названо в тексте или однозначный ориентир |
| Ориентир | Сильная историческая привязка |
| Атмосферная | Адрес в книге не дан — точка по смыслу |

У каждой точки есть блок «Почему точка здесь».
